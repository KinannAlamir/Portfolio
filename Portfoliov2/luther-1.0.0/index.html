Metadata Augmentation

An automated metadata enrichment system was developed for EDF's hydraulic documentation, drastically improving document retrieval for Hazard Studies. Combining classical ML (achieving 94.1-96.5% F1-scores) and LLMs for complex metadata extraction, the system enhanced data correlation and provides a scalable, cost-effective solution for technical documentation automation, foundational for future RAG improvements.

  • Machine Learning
  • LLM

2D Detectors in X-ray

Two-dimensional detectors are advanced technology recently adopted in X-ray material characterization. Optimizing their use requires software development for data management and processing. I contributed to designing and optimizing routines for processing 2D detector data. I addressed two key challenges: "tiling" and different integration methods required for materials to obtain an I(2θ) curve representing diffracted intensity variation.

  • Physics
  • Development
Project link
Acoustic Signal Analysis

This project aims to enhance the detection of chemical changes during mechanochemical syntheses through the analysis of acoustic signals. The focus was on converting existing MATLAB code to Python to improve accessibility. Two main techniques were used: an energy-based method and kurtosis analysis to detect sudden changes in sound, which signal chemical transformations.

  • Signal Processing
  • Python

Python Assembler

In this project, with a team of 4, our goal was to developed a custom Python assembler, focusing on lexical and syntactical analysis of regular expressions and Python instructions. The goal was to build a tool capable of generating and executing Python bytecode through a personalized assembler.

Dementia Detection

This project aims to create a predictive model that leverages both machine learning and generative AI (GAI) techniques. The model skillfully employs linguistic features extracted from text data to predict dementia diagnoses. The database utilized for this project is sourced from DementiaBank.

Energy Prediction

This project involved creating a model to predict various parameters related to the energy consumption of the GreEn-ER building. The focus was on applying machine learning algorithms, including polynomial regression with Lasso regularization and the Random Forest Regressor, to analyze building data from 2017 to 2019.
